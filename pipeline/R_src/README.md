R_scr/ (or pipeline/Rsrc/) README

Purpose: Contains R scripts for API ingestion and initial raw data retrieval.

Dependencies: List required R packages (e.g., tidycensus, tidyverse).

Warning: Ensure Census and CDC API keys configured in your R environment before running these scripts.

Output: These scripts output raw .csv files directly to data/raw/
